# 多维大纲台2

一个给多时空长篇用的本地大纲工具。单个 `index.html`，双击即可用，不依赖网络和服务。

## 三个视图

**时代色带**

- 竖直方向是一叠时代色带，默认：远古、明、清、民国、现代、未来。
- 每个事件卡落在它所属时代的色带上；每条色带只有一行卡片，卡片多了用横向滑条查看。
- 鼠标放到卡片上，卡片四条边会出现四个圆点。拖动任意一个圆点到另一张卡上，两张卡就连起来了。
- 连着线的事件组成主角折线，可以向多个方向分叉，不同连通分支用不同颜色。
- 没有连线的事件是灰卡，也就是草灰蛇线：伏笔、逻辑补丁、背景、备选素材。
- 鼠标移到连线上，线的中间会出现一个叉，点叉即可删除这条连线。
- 相连的卡片之间会留出更大的间距，方便看清连线；折线走预留通道，不压在卡片上。

**世界时间线**

- 只有一条时间线，按世界真实发生顺序排列。
- 所有卡片都在这里，包括连着折线的和灰卡。
- 卡片像抽屉，鼠标悬停自动展开，点击可以固定展开，展开后就是事件详情。

**分栏写作**

- 左侧是大纲和卡片标题，右侧按世界时间线从上到下排列所有卡片的详情，相当于正文流。
- 顶部工具栏有全局的「隐藏灰卡」开关，打开后所有视图里的草灰蛇线灰卡都会被隐藏。
- 右侧的详情可以直接编辑，长度会随内容自动增长。

## 卡片

每张卡就是一个小事件：

- 事件名称
- 事件详情
- 分类（可以在卡片上直接选择）
- 时代
- 世界时间、地点
- 连接关系（通过时代色带里拖动卡片边缘的圆点建立，或在右侧事件面板里查看和删除）

## 常用操作

- 拖动卡片：调整顺序，跨时代拖动会改变它所属的时代。
- 连线和断线：时代色带里拖动圆点连线，鼠标移到连线上点叉删除。
- 右侧「分类与时代」：新增、改名、排序、删除分类和时代。
- 导出 JSON：完整备份，可再导入。
- 导出 Markdown：按时代和世界时间整理的纯文本大纲。
- 数据自动保存在浏览器本地，清除浏览器数据会丢失，重要阶段请导出 JSON。

## 数据说明

示例数据是虚构的长篇《往复》，用来演示多时空、双线交替、折线分叉和草灰蛇线。所有内容都可以直接改。
